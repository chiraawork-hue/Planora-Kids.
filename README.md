# Planora Kids 🌈🐰

**Less Screen, More Wonder.** A pastel, mobile-first app for parents to discover offline children's activities.

## Features
- Smart Activity Finder by age, time, skill and household materials.
- Curated instructions for offline parent-child play.
- Printable A4 activity sheets.
- Favorites and weekly plan saved locally in the browser.
- Responsive Playful Pastel design and PWA manifest.

## Publish using GitHub Pages
Open **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then **Save**.

This is a static MVP: no accounts, synced data, payments or licensing yet. Browser storage can be cleared. Worksheet pages are first-pass activity sheets, not a finished curriculum. Review with a qualified early-childhood specialist before selling.
